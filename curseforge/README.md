# CurseForge upload checklist

For each mod, upload the matching `.jar` from `builds/26.1.2-neoforge/`.

1. **Create the project** on CurseForge (Minecraft > Mods).
   - Name / Summary: copy from `summary.txt` (or `metadata.json`).
   - Description: paste `description.md`.
   - Category, Game Version `26.1.2`, Mod Loader `NeoForge`, License `All Rights Reserved`.
   - Upload `logo.png` as the project avatar (400x400).
2. **Upload the file** for the project: the `.jar`, Release type `Release` (or `Alpha` if unreleased),
   Game Version `26.1.2`, Mod Loader `NeoForge`.
3. **Set the changelog** for that file from `changelog.md`.
4. **Add dependencies/relations** as needed (none required for these mods).
5. Repeat for each project. Use a **modpack** if you want players to install several at once.
